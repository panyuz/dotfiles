# Herdr Loop

仅在用户调用时使用。可附任务书或已有 TODO 路径。
主代理负责设计、拆分、纠偏和验收。长任务执行交给 Herdr 中的快速模型，以减少主代理 token 消耗。
主代理可按需调用 pi-subagents 的 `scout`、`worker`，辅助文件查阅、网络搜索、验证或其他短小独立任务。无需逐次申请派发许可。
派发辅助任务前读取 `pi-subagents` skill。只提供必要上下文，并要求返回摘要和证据。辅助任务不替代 Herdr 长任务执行。

## 1. 建立 TODO

在项目任务目录建立 `TODO.md`。已有文件则继续使用。
先写目标、写入范围、验收标准和本阶段时限，再列任务。
用一个文件跟踪计划和进度，不另建任务书或检查点。

```markdown
# 任务目标
范围：
验收标准：
阶段时限：
主代理终端：

## TODO
- [ ] 任务｜执行代理/终端｜模型｜产物｜状态或阻塞

## 交接
下一步：
```

## 2. 派发执行

读取 `hc --skill` 和 `herdr-app --skill`。具体参数查当前命令的 `--help`。
用 `hc` 启动和管理代理。用 `herdr-app` 按需展示或接管终端。

- 子进程默认模型为 `magpie/auto/deepseek-flash`。按任务难度选择 `high` 到 `max` 的思考强度。核实实际模型和思考强度；不可用时询问用户。
- 将主代理与每个子代理的会话、Herdr 终端都命名为“emoji + 任务概要”。例如主代理用 `🧭 招聘筛选监督`，子代理用 `📊 岗位入库`。仅改终端名不算完成。
- 创建子代理时明确给出名称。Pi 会话用 `/name <名称>` 命名；Herdr 终端按当前手册 rename。核对会话名和终端名，再记录到 TODO。任务变化时同步更新名称。
- 默认先启动一个后台交互式代理。有独立任务时再增加代理。
- 每次交付一个清楚的子任务。写明输入、允许修改的路径、产物、验收标准和时限。
- 在父端取得主代理终端地址。将明确地址和任务编号写进子任务指令。子代理不得再派发。
- 核对代理就绪及首任务送达。将终端名称、地址、实际模型和思考强度记入 TODO。
- 同一工作区只设一个写手。并行写入使用独立工作区。

## 3. 交互约定

子进程主动汇报。主进程有独立工作就继续做，只有需要子任务结果且无独立工作时才 wait。

**子进程：**
- 正常执行时继续工作，不逐步发送进度。
- 完成、需要主进程决策或失败时，先保存报告，再执行 `hc send <主进程明确地址> "任务编号｜完成/受阻/失败｜摘要｜报告绝对路径"`。
- 使用指令给定的主进程地址，不使用自身的 `HC_TERMINAL_ID` 作为目标。
- 汇报后结束当前轮次，保持交互式代理存活，等待下一条指令。不自行开始下一项任务。

**主进程：**
- 用 `hc send <子终端> "任务编号与任务指令"` 交付后续任务或返工要求。首任务随启动提交并核对送达。
- 需要等待时，执行 `hc wait --children any --timeout 60`。只有一个指定依赖时，可用 `hc wait <子终端> --timeout 60`。
- 按返回原因处理，不把 wait 返回当作完成：

| 事件 | 主进程动作 |
|---|---|
| 收到子进程汇报 | 按任务编号核对 TODO，读取报告和产物，再验收或处理问题。消息可能在工具返回后到达。 |
| 普通 timeout | 阶段未到期则继续等待。有独立工作则先做。不重发任务，不重启代理。 |
| 轮次结束但未收到报告 | 用 `hc get` 核对状态，再用 `hc read` 检查输出。仍无报告且代理可接收指令时，只要求补报。 |
| blocked 或权限请求 | 读取阻塞原因并询问用户。不用强制发送越过权限。 |
| error、异常退出或启动失败 | 保存状态并报告用户。未确认恢复方案前，不重启或替换代理。 |

等待期间不轮询抓屏，不用 sleep。主进程不因等待超时就结束任务。

## 4. 持续推进

循环执行，直到 TODO 全部验收完成：

1. 读取 TODO，将下一项可执行任务交给已登记的代理。
2. 按交互约定处理回报。主代理处理设计和依赖，不接管常规执行。
3. 读取实际产物并运行必要验证。只有验收通过才勾选 TODO。
4. 未通过时，将具体缺口交回原代理。通过后，更新证据路径并派发下一项。

只提供当前子任务所需的上下文。主代理只读摘要、相关产物和验收证据。
子进程汇报完成、轮次结束或 wait 返回，均不能代替产物验收。不静默更换模型。

## 5. 暂停与结束

用户要求状态时，只汇总 TODO。用户要求暂停或阶段到期时，暂停执行并写好交接。
恢复时，读取 TODO 并核实已登记终端。仍在工作的代理继续复用。
主代理退出前，暂停执行并保存下一步。只有用户明确要求时，才安排子代理继续运行。
全部验收后，报告产物路径。只清理本次创建且已验收的终端。
